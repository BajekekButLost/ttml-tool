Linux gets a Flatpak

Each release now includes a `.flatpak` file, the recommended way to run the tool on Linux. It brings its own WebKitGTK, GStreamer and GLib, so it starts on distros where the AppImage failed, such as Debian 13. The AppImage stays for existing installs but is no longer supported, and Flatpak installs skip the in-app updater.
