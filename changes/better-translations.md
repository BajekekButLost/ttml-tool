Translations that fit the app

All 15 languages were retranslated with the context of where each string appears, instead of word by word. Settings, buttons and messages now use natural wording and the same terms throughout, the new Start, Next and End names are translated everywhere, and counts like "3 words" use each language's proper plural forms. The language picker no longer marks names like TTML or Genius as untranslated, so complete languages show 100%.
