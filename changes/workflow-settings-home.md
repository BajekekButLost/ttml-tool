One full home for workflow settings

Preferences now includes the editor and preview options previously available only in ribbons, grouped into Edit mode, Time mode display, Syncing aids, Preview and Preview performance, each with an icon and a short description of what it does. Set-and-forget options such as layout, wrapping, FPS, fades, and editing gestures live in Preferences, while ribbons retain controls useful during lyric work. Sync offsets use the same whole-millisecond input behavior in both places.
