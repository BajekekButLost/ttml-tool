Removed tools Spicy Lyrics doesn't use

Obscene marks, empty beats, the NetEase, QQ Music, Spotify, Apple Music, ISRC and TTML-author fields in the metadata editor, and the upcoming-word highlight in Time mode are gone. Spicy Lyrics ignores all of them, so they only added clutter. TTML files that contain these marks still open normally; they're just left out when you save. Metadata already in a file still shows and saves as a regular metadata entry.
