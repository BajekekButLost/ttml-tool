Escape cancels word edits, and clicked dividers take arrow keys

Pressing Escape while editing a word in Edit mode now cancels the edit instead of being ignored, and canceling in Time mode can no longer save the text by accident. Clicking a word divider on the spectrogram now selects it, so holding the left or right arrow keeps nudging it; clicking anywhere else or pressing Escape hands the arrows back to audio seeking. The line count shown while dragging several lines sits in its own badge again instead of overlapping the line number.
