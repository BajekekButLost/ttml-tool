Edit mode tools: split typed lines, swap duet lines, reopen where you left off

Behind **Preferences › Workflow › Edit mode tools** (off by default). Type a whole line into **Insert word** and press Enter to get separate words, with your learned splits applied. **Tools › Swap main and duet lines** flips every line at once, and the line menu's **Swap main and duet** flips the selection; both undo in one step. Each project also reopens in Edit mode at the line you left it on, even after restarting the app.
